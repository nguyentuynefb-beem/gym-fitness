# Hệ thống Quản lý Phòng Gym / Fitness

Đề 23 — Triển khai và Quản trị Hệ thống Phần mềm.

## Thông tin sinh viên

- Họ tên: Nguyễn Đức Tuyên
- MSSV: DTC245200566
- Lớp: CNTT K23I

## Mục tiêu

Xây dựng website quản lý hội viên, gói tập, lịch tập và
huấn luyện viên; triển khai bằng Docker Compose.

## Công nghệ dự kiến

- Node.js, Express, EJS
- MySQL và phpMyAdmin
- Nginx
- Prometheus và Grafana
- Loki và Promtail

## Trạng thái hiện tại

- Đã thiết lập Ubuntu 24.04 trên WSL 2.
- Ubuntu được lưu trên ổ D.
- Đã kiểm tra kết nối Docker Desktop từ Ubuntu.
- Đã mở repository bằng VS Code trong WSL.
- Chưa triển khai ứng dụng và các dịch vụ của bài Gym.

## Hướng dẫn chạy

Sẽ bổ sung khi có phiên bản ứng dụng chạy được.
